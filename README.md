# Eigenfaces Facial Recognition using SVD

Acest proiect implementează un sistem de recunoaștere facială bazat pe metoda **Eigenfaces** (Fețe proprii), utilizând Descompunerea Valorilor Singulare (SVD - Singular Value Decomposition). 

Proiectul a fost dezvoltat în cadrul cursului de Calcul Numeric și pune accent pe înțelegerea matematică a reducerii dimensionalității în procesarea imaginilor.

## 📌 Caracteristici principale
- **Implementare SVD**: Extragerea trăsăturilor principale din setul de date cu imagini.
- **Analiză comparativă**: Benchmarking de performanță și acuratețe între implementarea operațiilor matriceale custom și funcțiile optimizate din `numpy.linalg`.
- **Documentație matematică**: Proiectul este însoțit de un raport detaliat redactat în LaTeX, care explică teoria din spatele metodei Eigenfaces și a descompunerii SVD.

## 📁 Structura proiectului
- `eigenfaces.ipynb`: Notebook-ul principal care conține codul, antrenarea modelului și vizualizările.
- `documentetie.pdf`: Documentația tehnică și matematică (redactată în LaTeX).
- `requirements.txt`: Dependințele necesare pentru rularea codului.
